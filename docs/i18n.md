# Translations

inua's text is English at its source and translated through gettext
catalogs, keyed by the English: one `.po` file a language in
`internal/i18n/locales/`, embedded in the programs. Stage 0: the
machinery, and System Monitor in Simplified Chinese (`zh_CN`) as the
example; the shell and the other apps follow.

## The language

The programs choose it once, at start, from the environment as gettext
does: `LANGUAGE` (a list, `fr:de`), else `LC_ALL`, `LC_MESSAGES`, `LANG`.
`zh_CN.UTF-8` tries `zh_CN`, then `zh`; a language without a catalog, and
English, leave the text as written. To try one:

```sh
LANGUAGE=zh_CN inua-apps system-monitor
```

## Marking text

In Go (`internal/i18n`):

- `i18n.T("Pause")`: a message.
- `i18n.Tf("Process %d has ended.", pid)`: a format, filled in. A
  translation may take the arguments in another order: `%[2]s … %[1]d`.
- `i18n.Nf("%d core", "%d cores", n, n)`: the form for n, filled in.
- `i18n.M("Resident")`: marks a string kept in a table, or passed on, and
  leaves it as it is; `i18n.T` translates it where it is shown. A string
  that is also a key (a map's) keeps its English there.

Dates are Go time layouts, such as `Jan 2 15:04`: translate them as
layouts, writing Go's reference date (Mon Jan 2 15:04:05 2006) in the
language's order and words, as `1月2日 15:04`.

Keep whole sentences in one message, with their numbers and names as
arguments, not joined from pieces: word order differs between languages.

In Blueprint layouts, `_("Filter by name, PID or user")`: the compiled
`.ui` marks it `translatable="yes"`, and `gtkx.Load` translates it before
GTK reads the layout.

## Updating the catalogs

```sh
make i18n
```

gathers every marked string into `po/inua.pot`, the template, and brings
each catalog up to date with it: new messages added untranslated (an empty
`msgstr`), gone ones dropped, translations kept. CI fails when the
template or a catalog is out of date. Commit both with the change that
marks the text.

## Adding a language

Copy the template's header into `internal/i18n/locales/LANG.po` with the
language's `Language:` and `Plural-Forms:` (`nplurals=1` for languages
without plurals, such as Chinese and Japanese; two forms, singular for 1,
otherwise), run `make i18n`, and fill in each `msgstr` (`msgstr[0]`,
`msgstr[1]` … for plurals). A translation marked `#, fuzzy` is not used.
The tests check that each translation takes its message's arguments.
